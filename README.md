# StoryWeaver Mobile

Ứng dụng Expo SDK 52 / React Native (Parent + Kid Mode), chỉ gọi Backend chính thức qua HTTP.

```
cd apps/mobile
cp .env.example .env   # đặt EXPO_PUBLIC_API_URL
npm install
npx expo start
```

Tài liệu: `docs/mobile/` (mục lục `docs/mobile/README.md`; hiện trạng `MOBILE_STATUS.md`; API mapping; kế hoạch test R9-B).
